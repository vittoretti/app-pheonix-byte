# app-pheonix-byte
Entrega de uma atividade em dupla de um App em React Native, usando useState e transferência de valores entre telas junto dos conhecimentos pré-adquiridos em aula e pesquisas externas.
O aplicativo se trata de um app de compras da loja de informática "Pheonix Byte", com uma tela de produtos, descrição do produto e cadastro para compra.
Feito por Matheus Vittoretti Amoroso da Costa e Luccas Santos Barbosa.
